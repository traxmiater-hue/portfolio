# Парсер с пагинацией и карточками → Excel и CSV

Демо на quotes.toscrape.com (открытая песочница для обучения парсингу):

- обходит все страницы каталога, собирает 100 цитат с авторами и тегами;
- параллельно заходит в карточку каждого из 50 авторов: дата и место рождения, краткая биография;
- повторяет запрос при сбоях сети, бережно нагружает сайт;
- сохраняет Excel (листы «Цитаты», «Авторы», «Теги» с диаграммой, фильтры, ссылки) и CSV для импорта.

Весь сбор — около 6 секунд.

```
pip install requests beautifulsoup4 lxml openpyxl
python parser.py              # всё
python parser.py --tag love   # только один тег
```
