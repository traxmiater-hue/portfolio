# Новостной дайджест по ключевым словам: RSS → Excel + Telegram

- собирает новости из нескольких RSS (демо: Хабр, Лента, vc.ru), источники и слова — в `config.json`;
- оставляет только новости с вашими ключевыми словами за последние N часов;
- убирает дубли: одна новость на разных сайтах попадёт один раз (по похожести заголовков);
- сохраняет Excel с фильтрами и ссылками и шлёт дайджест в Telegram.

```
pip install requests openpyxl
python digest.py --hours 24
```

Запуск по расписанию — получаете утренний дайджест в Telegram без ручного мониторинга.
