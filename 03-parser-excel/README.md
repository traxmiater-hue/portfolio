# Парсер каталога товаров → Excel

Собирает каталог интернет-магазина и сохраняет его в аккуратно оформленный Excel.
Демо сделано на [books.toscrape.com](https://books.toscrape.com) — открытой песочнице для парсинга
(1000 товаров, 50 страниц каталога, 50 категорий).

Готовый результат: [`example_full_catalog.xlsx`](example_full_catalog.xlsx) — весь каталог, собран за 52 секунды.

## Что собирается

| Поле | Откуда |
|---|---|
| Название, цена, рейтинг, наличие, фото | страница каталога |
| Категория, артикул (UPC), остаток в штуках, число отзывов, описание | карточка товара |

## Что в Excel

- **Товары** — таблица с автофильтром, закреплённой шапкой, кликабельными ссылками на товар и фото,
  цветовой шкалой цены (дешёвые — зелёные, дорогие — красные).
- **Сводка** — по категориям: количество, средняя/мин/макс цена, средний рейтинг, суммарный остаток + диаграмма.
- **Ошибки** — появляется, только если какие-то карточки не открылись (сбор при этом не падает).

## Запуск

```bash
pip install -r requirements.txt
python parser.py                       # весь каталог
python parser.py --pages 3             # первые 3 страницы
python parser.py --category Poetry     # одна категория
python parser.py --no-details          # только список, без карточек — в разы быстрее
python parser.py --out prices.xlsx     # своё имя файла
```

Дополнительно: `--workers 8` — параллельные запросы, `--delay 0.1` — пауза между запросами (бережём сайт).

## Надёжность

- повтор запроса до 3 раз с растущей паузой при сетевых ошибках;
- одна сломанная карточка не останавливает сбор — она попадает на лист «Ошибки»;
- переход по страницам по кнопке «next», а не по угаданным номерам — не ломается при изменении числа страниц.

## Как адаптировать под другой сайт

Поменять CSS-селекторы в `parse_listing` (список) и `parse_details` (карточка). Остальное — HTTP-клиент,
параллельность, Excel-отчёт — переиспользуется без изменений.

## Стек

Python 3.10+, requests, BeautifulSoup + lxml, openpyxl.
