# Бот онлайн-записи к мастеру

Telegram-бот для салона, барбершопа, мастера маникюра — любого бизнеса с записью по времени.

## Что умеет

**Клиент**
- выбирает услугу → день → свободное время (занятые слоты скрыты автоматически);
- оставляет телефон одной кнопкой (или вводит вручную), второй раз номер не спрашивается;
- видит свои записи и отменяет их;
- получает напоминание за 2 часа.

**Владелец** (`/admin` или кнопка в меню)
- записи на сегодня, завтра, неделю — с суммой выручки;
- отмена записи с автоматическим уведомлением клиента;
- выгрузка всех записей в CSV (открывается в Excel);
- мгновенные уведомления о новых записях и отменах.

**Надёжность**
- двойная запись на одно время невозможна (проверка в транзакции SQLite);
- нельзя записаться в прошлое и ближе чем за час;
- выходные дни, часы работы, шаг сетки и длительность услуг — в `config.py`.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env      # вписать BOT_TOKEN и ADMIN_IDS
python bot.py
```

Токен — у [@BotFather](https://t.me/BotFather) (`/newbot`). Свой Telegram ID — у [@userinfobot](https://t.me/userinfobot).
Владелец должен один раз нажать `/start` в боте, иначе Telegram не даст боту написать ему первым.

## Тесты

```bash
pip install pytest
pytest -q
```

Тесты прогоняют полный сценарий записи на «фейковом» Telegram — без токена и интернета.

## Как адаптировать

Всё про бизнес — в `config.py`: название, адрес, услуги с ценами и длительностью, часы работы, выходные.

## Стек

Python 3.10+, python-telegram-bot 21, SQLite. Файлы: `bot.py` — диалоги, `slots.py` — расчёт свободного времени, `storage.py` — база.
