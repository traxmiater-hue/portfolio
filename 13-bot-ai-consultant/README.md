# Telegram-бот-консультант на нейросети

Консультирует клиентов по базе знаний компании (демо — онлайн-школа английского):

- OpenAI или Gemini (через OpenAI-совместимый адрес) — выбирается в настройках;
- отвечает **только** по фактам из `knowledge.md`, не выдумывает цены;
- помнит контекст диалога, лимит запросов в сутки на пользователя;
- «Позвать менеджера» → диалог уходит в группу менеджеров, ответ реплаем возвращается клиенту;
- журнал вопросов и ответов в SQLite, уведомления о новых пользователях.

```
pip install -r requirements.txt
set BOT_TOKEN=... & set OPENAI_API_KEY=... & set MANAGERS_CHAT_ID=...
python bot.py
```

Стек: Python 3.11, python-telegram-bot 21, openai, SQLite.
