## Как запустить

- **Сайты** — открыть `index.html` в браузере, сборка не нужна.
- **Python-проекты** — в папке проекта: `pip install -r requirements.txt`, затем запуск по README проекта.
  Токены ботов задаются в `.env` (пример — `.env.example`), в репозитории их нет.
- **CRM** — `python seed.py` создаёт базу с демо-данными, `python app.py` запускает сервер.
