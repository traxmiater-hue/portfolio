# Поток CRM — мини-CRM для заявок

Веб-приложение для небольшого бизнеса: все заявки в одном месте, статусы, ответственные, история, аналитика.

**Демо-вход:** `admin` / `demo123` (руководитель) или `manager` / `demo123` (менеджер).

## Возможности

- **Дашборд** — новые заявки за месяц, активная воронка в рублях, выручка, конверсия;
  график заявок по неделям, воронка по статусам, эффективность источников, лента последних действий.
- **Список заявок** — поиск по имени, телефону, компании, комментарию; фильтры по статусу, источнику,
  менеджеру; сортировка; постраничный вывод; выгрузка текущей выборки в CSV (открывается в Excel).
- **Карточка заявки** — редактирование, назначение менеджера, комментарии; история изменений статуса
  и суммы пишется автоматически.
- **Канбан-доска** — перетаскивание карточки меняет статус (сохраняется сразу, без перезагрузки).
- **Роли** — удалять заявки может только руководитель.
- **API для сайта** — заявки с лендинга или из Telegram-бота падают в CRM автоматически.

## Запуск

```bash
pip install -r requirements.txt
python seed.py     # создаёт crm.db со 150 демо-заявками
python app.py      # http://127.0.0.1:5000
```

Переменные окружения (для боевого запуска обязательно задать свои):

| Переменная | Зачем |
|---|---|
| `CRM_SECRET` | ключ подписи сессий |
| `CRM_API_TOKEN` | токен для приёма заявок с сайта |
| `CRM_DB` | путь к базе (по умолчанию `crm.db` рядом с `app.py`) |

## Приём заявок с сайта

```js
fetch("https://ваш-домен/api/public/leads", {
  method: "POST",
  headers: { "Content-Type": "application/json", "X-Token": "ваш CRM_API_TOKEN" },
  body: JSON.stringify({ name: "Марина", phone: "+7 900 000-00-00", source: "Сайт", note: "Тариф «С разбором»" })
});
```

Ответ `201 {"ok": true, "id": 151}`. Заявка появляется в статусе «Новая» с отметкой в истории.

## Безопасность

Пароли хранятся в виде хэшей, все формы и AJAX-запросы защищены CSRF-токеном, SQL — только
параметризованные запросы, редирект после входа — только на внутренние страницы.

## Тесты

```bash
pip install pytest
pytest -q
```

8 тестов: вход и CSRF, все страницы, создание/редактирование/история, валидация, канбан-API, права, публичный API и CSV.
