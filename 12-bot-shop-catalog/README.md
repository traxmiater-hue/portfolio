# Telegram-бот: каталог услуг, корзина и заказ

Бот для небольшой компании (демо — студия уборки «Чистый дом»):

- главное меню, контакты;
- каталог по разделам, карточка услуги с описанием, ценой и фото;
- корзина: добавить несколько услуг, удалить, посмотреть итог;
- оформление: имя, телефон с проверкой, комментарий → заказ сразу приходит администратору;
- каталог редактируется **без программиста**: `catalog.json` или опубликованная Google Таблица (CSV).

Запуск:

```
pip install -r requirements.txt
set BOT_TOKEN=...        # токен от BotFather
set ADMIN_CHAT_ID=...    # куда слать заказы (личка или группа)
python bot.py
```

Стек: Python 3.11, python-telegram-bot 21, requests.
