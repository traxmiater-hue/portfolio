# Мониторинг цен и наличия → Excel-отчёт и Telegram

Каждый запуск:

1. собирает цены и наличие товаров (демо — books.toscrape.com);
2. сохраняет снимок в SQLite — копится история цен;
3. сравнивает с прошлым запуском: что подешевело, подорожало, появилось или закончилось;
4. строит Excel-отчёт с подсветкой (зелёный — дешевле, красный — дороже) и ссылками;
5. по желанию шлёт сводку в Telegram.

Запуск по расписанию — Планировщик Windows или cron, например каждое утро в 8:00.

```
pip install requests beautifulsoup4 lxml openpyxl
python monitor.py --pages 5                        # 100 товаров
python monitor.py --pages 5 --simulate-yesterday   # демо: «вчерашний» снимок с изменёнными ценами
```

В демо «вчерашние» цены созданы флагом `--simulate-yesterday`, чтобы было видно, как выглядит отчёт.
