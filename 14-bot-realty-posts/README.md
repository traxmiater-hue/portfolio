# Бот публикации объявлений о квартирах

Риелтор присылает боту фото/видео квартиры и описание «как есть» — бот:

1. разбирает хаотичный текст в шаблон: комнаты, адрес, цена (+ку / счётчики / всё включено), залог, этаж, остальное;
2. показывает превью с кнопками «Опубликовать / Исправить текст / Отмена»;
3. публикует пост с альбомом в группу (бот — администратор).

```
сдаю 1к квартиру на Кремлевская 19, 5/9 эт,          1к квартира
свежий ремонт, 50000+ку залог 20т, можно с котом  →  Кремлевская 19
                                                      50 000+ку
                                                      Залог 20т
                                                      5/9 эт.

                                                      Свежий ремонт, можно с котом
```

Разбор покрыт тестами: `pytest test_parse.py`.

Запуск: `BOT_TOKEN=... OWNER_ID=... TARGET_CHAT=@group python bot.py`

Стек: Python 3.11, python-telegram-bot 21, регулярные выражения (без платного ИИ).
